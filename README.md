# referral-system-go

# B2B Referral Engine Microservice

High-performance, scalable referral management service built with Go.

## 🛠 Tech Stack

* **Language:** Go (1.26.5+)
* **Routing:** `go-chi/chi`
* **Database:** PostgreSQL / `pgx`

## 🏗 Architecture & Design Decisions

* **Vertical Slice Architecture:** Domain features are grouped by business capabilities (e.g., `features/referrals`, `features/auth`), maximizing co-location and minimizing coupling.

## 🚀 Getting Started

### Prerequisites
* Go 1.23+
* PostgreSQL 16+
